# Project Documentation Builder

Builds or comprehensively restructures a source-backed project documentation system under `documents/documentation/`. Each run keeps its ledger and validation audit in a unique folder under `documents/tasks/documentation/build/`.

Invoke with `$project-documentation-builder`. Use the bundled record initializer and validator from the installed skill directory; the skill does not install helpers into the target project or depend on other skills.

For claims about visible application behavior, follow the target project's browser policy. Ego Browser is the recommended verifier when it is installed and authorized. Browser verification is not required for work without browser-visible claims.
